# List of fonts installed in the system

> [!Note]
> All the fonts are stored in the system directory (/usr/share/fonts) to enable access for all users. If you want to install fonts for a single user, you can place them in the ~/.local/state/fonts directory.
> - Remember to download all three variants of the font (Regular, Mono and Propo) after reinstallation (generally included together when downloading from Arch repos and [Nerd Fonts](https://www.github.com/ryanoasis/nerd-fonts/)).
> - Copy the 'special' fonts from this folder (~/.fonts) to the system directory (/usr/share/fonts) to make them available for all users.

- CaskaydiaCove Nerd Font
- ComicShannsMono Nerd Font
- DepartureMono Nerd Font
- Hobo
- JetBrainsMono Nerd Font
- TW Cen MT (for presentations)
- Waycat (special)
